# `.github` de Kairós Tech

Repositorio de documentación común y políticas transversales de la organización **kairos-Tech-UY**.

## Qué contiene este repositorio

- [profile/README.md](profile/README.md): página pública del perfil de GitHub de Kairós Tech.
- [CONTRIBUTING.md](CONTRIBUTING.md): guía general para contribuciones.
- [SECURITY.md](SECURITY.md): política para reportar vulnerabilidades.
- [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md): plantilla base para PRs.

## Contexto de la organización

Kairós Tech es un equipo académico de **UTEC (Uruguay)** que desarrolla **Curupí**, una plataforma en evolución para digitalización de comprobantes y procesos administrativos con arquitectura de microservicios orientada a eventos.
